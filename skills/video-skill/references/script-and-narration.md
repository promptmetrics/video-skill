# Part 1: Video Structure

Standard structures for educational videos of different lengths. Use these during **Phase 1.5** to plan your narrative arc and chapter breakdown, and during **Phase 2** for scene splitting and timing allocation.

## General Structure

Every educational video follows this pattern:

```
┌─────────────────────────────────────────┐
│  1. HOOK         - Grab attention       │
│  2. INTRO        - Set expectations     │
│  3. CONTENT      - Main teaching        │
│  4. SUMMARY      - Reinforce learning   │
│  5. OUTRO        - Close and CTA        │
└─────────────────────────────────────────┘
```

## Structure by Duration

### Short Video (1-3 minutes)

```
Total: 90-180 seconds

┌─ Hook (5-10s) ────────────────────────────┐
│  • Surprising fact or question            │
│  • Visual that creates curiosity          │
└───────────────────────────────────────────┘
        ↓
┌─ Introduction (10-15s) ───────────────────┐
│  • Topic statement                        │
│  • Preview of what viewer will learn      │
└───────────────────────────────────────────┘
        ↓
┌─ Main Content (60-120s) ──────────────────┐
│  • 2-3 key points maximum                 │
│  • One concept per segment                │
│  • Visual demonstration for each          │
└───────────────────────────────────────────┘
        ↓
┌─ Summary (10-15s) ────────────────────────┐
│  • Quick recap of key points              │
│  • Single takeaway message                │
└───────────────────────────────────────────┘
        ↓
┌─ Outro (5-10s) ───────────────────────────┐
│  • Thank viewer                           │
│  • Optional: Related topic tease          │
└───────────────────────────────────────────┘
```

**Example Timeline (2 minutes):**
```
0:00 - 0:08  Hook
0:08 - 0:20  Introduction
0:20 - 1:40  Main Content (3 segments × 25-30s)
1:40 - 1:52  Summary
1:52 - 2:00  Outro
```

```
│    • Basic concept introduction           │
│    • Visual demonstration                 │
│                                           │
│  Segment 2: Deep Dive (45-60s)            │
│    • Detailed explanation                 │

│                                           │
│  Segment 3: Application (30-45s)          │
│    • Real-world examples                  │
```

## Pacing Guidelines

### Information Density

| Video Length | New concepts/minute | Words/minute (narration) |
|--------------|---------------------|--------------------------|
| Short (1-3m) | 1-2 concepts | 120-140 words |
| Medium (3-5m) | 1.5-2 concepts | 130-150 words |
| Long (5-10m) | 1-1.5 concepts | 140-160 words |

### Visual Pacing

- **Scene duration**: 3-8 seconds average
- **Maximum static hold**: 5 seconds
- **Minimum between cuts**: 2 seconds
- **Complex visuals**: Allow 5-10 seconds

### Cognitive Load Management

```
┌─────────────────────────────────────────┐
│  Rule of 3:                             │
│  • Max 3 new concepts per segment       │
│  • Max 3 visual elements animating      │
│  • Max 3 seconds without visual change  │
└─────────────────────────────────────────┘
```

## Transition Recommendations

### Between Segments

| Transition Type | When to Use | Duration |
|-----------------|-------------|----------|
| Fade | Topic change | 0.5-1s |
| Slide | Continuing same topic | 0.3-0.5s |
| Zoom | Focusing on detail | 0.5-0.8s |
| Wipe | New chapter | 0.5-0.8s |

### Within Segments

- Use subtle animations (fade, slide)
- Keep transition duration under 0.5s
- Maintain visual continuity

# Part 2: Script Writing

Write a complete narrative script before breaking it into storyboard scenes. This phase focuses purely on **what to tell** and **how to tell it well**, without worrying about visual specifications, frame numbers, or animation parameters.

## Why Script First

The script phase exists to separate **narrative creation** from **visual specification**:

- **Here (Script)**: Focus on storytelling — what to say, in what order, with what analogies
- **Next (Storyboard)**: Focus on visualization — how to show it on screen with precise parameters

This separation ensures:
1. Better narrative quality (full attention on story coherence)
2. Cheaper iteration (modifying text is much faster than modifying storyboard specs)
3. Easier review (users can evaluate "is the story good?" without wading through frame numbers)
4. Better LLM output (each phase has a focused, manageable cognitive load)

## Writing Process

### Step 1: Define Narrative Strategy

Before writing any script text, decide:

**Entry Angle** — How to pull the audience in:
- Question: "Have you ever wondered why...?"
- Scenario: "Imagine you are..."
- Challenge: "Most people think X, but actually..."
- Story: "In 1905, a young clerk in a patent office..."

**Core Metaphor** — A familiar concept that maps to the topic:
- Good: "DNA is like a recipe book" (familiar → unfamiliar)
- Good: "The internet is like a postal system" (concrete → abstract)
- Bad: "Quantum mechanics is like a wave" (still abstract)

**Knowledge Order** — What must come before what:
```
Example for "How planes fly":
1. First: planes are heavy → creates the question
2. Second: four forces → gives the framework
3. Third: lift (the answer) → depends on knowing the question
4. Fourth: wing shape → explains HOW lift works
5. Fifth: balance → ties everything together
```

### Step 2: Write the Full Script

Write as if you're speaking to the audience. Key principles:

- **Write complete narration text** — every word that will be spoken
- **Add visual intents** — brief descriptions of what should appear on screen (NOT technical specs)
- **Mark emphasis** — bold for stressed words, italic for softer tone
- **Use natural language** — read it aloud to check flow

**Visual Intent vs Visual Specification:**
```
✓ Visual intent (script phase):
  "Show the airplane from the side with four arrows representing the forces"

✗ Visual specification (storyboard phase):
  "Airplane SVG centered at (960, 540), 300x120px, ForceArrow components
   with spring(damping:12) at frames 240-360"
```

### Step 3: Annotate Pacing

After the full script is written, go back and mark:

- Where to **speed up** (information the audience already half-knows)
- Where to **slow down** (new or counterintuitive concepts)
- Where to **pause** (let the audience process before moving on)
- Where to **build tension** (short sentences leading to a reveal)

### Step 4: Self-Review

Read the entire script from start to finish and check:

1. **Coherence**: Does the story make sense as a continuous narrative?
2. **Progressive building**: Does each section build on the previous one?
3. **Audience fit**: Is the language appropriate for the target audience?
4. **Completeness**: Are all learning objectives covered?
5. **Engagement**: Would YOU want to keep watching?

## Narrative Techniques

### Story Arc Design

Every good educational video follows an arc:

```
Engagement ▲
           │         ╱╲
           │        ╱  ╲        ╱╲
           │   ╱╲  ╱    ╲      ╱  ╲
           │  ╱  ╲╱      ╲    ╱    ╲
           │ ╱              ╲  ╱      ╲
           │╱                ╲╱        ╲___
           └──────────────────────────────→ Time
           Hook  Build  Climax  Resolve  End
```

- **Hook**: Highest initial curiosity — a question or surprise
- **Build**: Gradually introduce concepts, each raising new questions
- **Climax**: The "aha moment" — when the key insight clicks
- **Resolve**: Connect everything together
- **End**: Satisfaction + lingering curiosity

### Metaphor and Analogy Design

Good metaphors for educational content:

| Technique | When to Use | Example |
|-----------|-------------|---------|
| **Direct analogy** | New concept similar to familiar one | "Electrons orbit like planets" |
| **Contrast analogy** | Correcting misconceptions | "Unlike a battery, a capacitor..." |
| **Scale analogy** | Making large/small tangible | "If an atom were a stadium..." |
| **Process analogy** | Explaining mechanisms | "Encryption is like a secret language..." |

Rules for metaphors:
- Introduce the metaphor early, reference it throughout
- Acknowledge where the metaphor breaks down (if relevant)
- Don't mix metaphors — one central metaphor per video
- Ensure the familiar side is truly familiar to the target audience

### Knowledge Scaffolding

Build knowledge like a staircase — each step supports the next:

```
Step 4: [Advanced concept]    ← Requires steps 1-3
Step 3: [How it works]        ← Requires steps 1-2
Step 2: [Basic framework]     ← Requires step 1
Step 1: [Foundation concept]  ← No prerequisites
```

Anti-pattern: **Forward references**
```
✗ "As we'll see later, this is because of quantum tunneling..."
  (Don't reference concepts not yet explained)

✓ "Remember how we said electrons are like balls on a hill?
   Well, imagine that ball could sometimes pass through the hill..."
  (Build on what's already established)
```

### Emotional Curve

Plan the emotional journey:

| Phase | Emotion | How to Create |
|-------|---------|---------------|
| Opening | **Curiosity** | Ask a surprising question |
| Foundation | **Interest** | Reveal the framework |
| Deep dive | **Focus** | Step-by-step explanation |
| Key insight | **Wonder** | The "aha!" moment |
| Application | **Connection** | Real-world relevance |
| Closing | **Satisfaction** | Everything clicks together |

## Script Examples

### Short Script Example (1-2 min): Why Is the Sky Blue?

```markdown
# Script: Why Is the Sky Blue?

## Core Message
- **One-line summary**: Light from the sun gets scattered by the atmosphere, and blue light scatters the most
- **Target audience**: Children (8-12)
- **Learning objectives**: Understand that sunlight contains all colors; know that air scatters blue light more
- **Estimated duration**: 1.5 minutes

## Narrative Strategy
- **Entry angle**: Question — "Have you ever wondered why?"
- **Core metaphor**: Light as a bouncing ball — different colors bounce differently
- **Emotional arc**: Curiosity → Surprise (sunlight is all colors) → Understanding → Delight
- **Knowledge building order**: Sky is blue (observation) → sunlight has all colors (foundation) → air scatters light (mechanism) → blue scatters most (answer)

## Full Script

### Opening
> "Every day you look up at the sky, and it's **blue**.
> But have you ever wondered—why blue, and not green or red?"
>
> Visual intent: Blue sky, then flash different colored skies to show the question

### Chapter 1: Sunlight's Secret
> "The secret starts with sunlight.
> Sunlight looks white, right?
> But actually, it's a mixture of **all the colors**!
> Red, orange, yellow, green, blue, violet—they're all hiding inside sunlight."
>
> Visual intent: White sunlight beam splits into rainbow colors (like a prism)

### Chapter 2: The Bouncing Game
> "When sunlight passes through the atmosphere, it bumps into countless *tiny* air molecules.
> These molecules make the light 'bounce around'.
> But here's the interesting part—**blue** light is the easiest to bounce,
> it scatters in every direction.
> And red light? Most of it passes straight through."
>
> Visual intent: Show light particles hitting air molecules, blue ones bouncing everywhere, red ones passing through

### Summary
> "So what we see when we look up is blue light bouncing at us from every direction.
> The whole sky is glowing blue!"
>
> Visual intent: Pull back to show the whole sky filled with scattered blue light

### Ending
> "By the way, do you know why the sky turns *orange-red* at sunset?
> That's because—well, I'll leave that one for you to think about!"
>
> Visual intent: Sunset transition, ending with a question mark

## Pacing Notes
- **Speed up**: The color listing (red, orange, yellow...) — keep it rhythmic
- **Slow down**: "Blue light scatters the most" — this is the key insight
- **Pause**: After "Why blue and not green or red?" — let the question sink in
```

## Script Review Checklist

Before passing the script to the Storyboard phase, verify:

### Narrative Quality
- [ ] The story has a clear beginning, middle, and end
- [ ] The hook creates genuine curiosity or engagement
- [ ] Each chapter has a clear purpose in the overall narrative
- [ ] Transitions between chapters feel natural
- [ ] The conclusion provides satisfying closure

### Educational Quality
- [ ] All learning objectives from Phase 1 are addressed
- [ ] Knowledge is built progressively — no forward references
- [ ] Concepts are explained at the right level for the audience
- [ ] Analogies/metaphors are accurate and accessible
- [ ] Key terms are introduced and explained naturally

### Script Quality
- [ ] Narration reads naturally when spoken aloud
- [ ] Sentence length is appropriate for the audience
- [ ] Emphasis markers are placed on truly important words
- [ ] Visual intents give enough direction without over-specifying
- [ ] Pacing notes identify where to speed up, slow down, and pause

### Completeness
- [ ] Core message is defined
- [ ] Narrative strategy is documented
- [ ] Full narration text is written for every section
- [ ] Visual intents accompany each section
- [ ] Pacing notes are provided
- [ ] Estimated duration is realistic

# Part 3: Narration Writing

Detailed writing principles and techniques for narration text.

## Writing Principles

### Core Guidelines

1. **Clarity First**: Every sentence should be immediately understandable
2. **One Idea Per Sentence**: Don't cram multiple concepts together
3. **Active Voice**: "The wing creates lift" not "Lift is created by the wing"
4. **Concrete Examples**: Abstract → Concrete → Abstract

### Audience Adaptation

#### For Children (6-12 years)

```markdown
Language:
- Use simple, everyday vocabulary
- Short sentences (8-12 words average)
- Avoid jargon, or explain it immediately
- Use "you" to create connection

Tone:
- Curious and wondering
- Encouraging and positive
- Like a friendly teacher or older sibling

Examples:
✓ "Have you ever tried sticking your hand out of a car window?"
✗ "The principles of aerodynamics indicate..."

✓ "It's like a magic trick!"
✗ "This is an inevitable consequence of the laws of physics."
```

#### For Teenagers (13-18 years)

```markdown
Language:
- Can use some technical terms (with brief explanations)
- Medium sentence length (12-18 words)
- Occasional humor is welcome
- Reference current topics/interests

Tone:
- Conversational but informative
- Respect their intelligence
- Connect to real-world applications
```

#### For Adults (General)

```markdown
Language:
- Technical terms acceptable
- Varied sentence structure
- More complex relationships between ideas
- Nuanced explanations

Tone:
- Professional but accessible
- Assumes basic knowledge
- Provides depth and context
```

## Script Structure

### Scene Script Template

```markdown
## Scene [Number]: [Title]

### Narration
[Write the exact words to be spoken]

### Timing Notes
- Total duration: [X] seconds
- Words: [X] (aim for 2.5-3 words/second)
- Pauses: [mark significant pauses with ...]

### Visual Sync Points
- "[Key phrase]" → [Visual action]
- "[Key phrase]" → [Visual action]

**Bold** = Stressed words
*Italic* = Softer tone
[PAUSE] = Deliberate pause
```

### Example Script

```markdown
## Scene 3: Explaining Lift

### Narration
"Now let's look at the first force—**lift**.[PAUSE]

Lift is the *most important* force that makes a plane fly.
It comes from the airplane's wings.

Look at the shape of this wing:[PAUSE]
The top is **curved**, and the bottom is fairly **flat**.

When the plane moves forward,
air flows over the top and bottom of the wing *at the same time*.

Because the top is curved, the air has to travel a **longer** path,
so it flows **faster**.

There's a remarkable rule here:
the faster air flows, the **lower** its pressure.[PAUSE]

So the pressure above the wing... is lower than below.
The air underneath pushes the wing **upward**!

That's the secret of lift!"

### Timing Notes
- Total duration: 45 seconds
- Words: ~140 words (~3 words/second)
- Major pauses at concept transitions

### Visual Sync Points
- "shape of this wing" → Show wing cross-section
- "top is curved" → Highlight curved top
- "air flows over the wing" → Animate airflow
- "flows faster" → Speed up top airflow animation
- "pressure is lower" → Show pressure difference
- "pushes upward" → Animate lift force arrow

### Emphasis
- "lift" - Key term, emphasize
- "curved" / "flat" - Contrast
- "faster" / "lower" - Cause and effect
- "push" - Action word
```

## Writing Techniques

### Hook Patterns

**Question Hook**
```
"Have you ever wondered why [surprising observation]?"
"If I told you [counterintuitive fact], would you believe me?"
```

**Scenario Hook**
```
"Imagine you're [relatable situation]..."
"Close your eyes and picture [vivid scene]..."
```

**Challenge Hook**
```
"Today, we're going to solve a mystery: [mystery]"
"There's a question that has troubled humanity for thousands of years: [big question]"
```

### Explanation Patterns

**The Analogy Pattern**
```
"[Complex concept] is like [familiar thing].
Just as [analogy explanation],
[concept] works the same way."

Example:
"A wing generating lift is like your hand out the car window.
When you tilt your palm upward, the air pushes your hand up.
A wing uses the same principle, just engineered more precisely."
```

**The Build-Up Pattern**
```
"First, [foundation concept].
Next, [building on that].
Finally, [conclusion]."
```

**The Contrast Pattern**
```
"You might think [common misconception].
But actually, [correct understanding].
The difference is [key difference]."
```

### Transition Phrases

**Moving to Next Point**
```
- "Now let's look at..."
- "Next..."
- "So... how does that work?"
- "Speaking of which, you might ask..."
```

**Connecting Ideas**
```
- "Which means..."
- "Therefore..."
- "In other words..."
- "That's why..."
```

**Summarizing**
```
- "So, to summarize..."
- "In short..."
- "Remember this:"
- "Most importantly..."
```

## Pacing and Rhythm

### Speech Rate Guidelines

| Audience | Words/Minute | Syllables/Second (spoken pace) |
|----------|--------------|----------------------------|
| Children | 100-120 | ~2.5-3 |
| Teenagers | 120-140 | ~3-3.5 |
| Adults | 140-160 | ~3.5-4 |

### Pause Types

```
[.]     Short pause (0.3-0.5s) - Between sentences
[..]    Medium pause (0.5-1s)  - Between ideas
[...]   Long pause (1-2s)      - Before important reveal
[BEAT]  Dramatic pause (2-3s)  - For emphasis
```

### Rhythm Patterns

**Building Tension**
```
Short sentence. [.]
Another short one. [.]
Then something a bit longer to develop the idea. [..]
And finally... [BEAT]
The revelation that ties it all together!
```

**Explaining Complex Ideas**
```
[State the concept simply.] [..]
[Expand with detail.] [.]
```

# Part 4: On-Screen Captions & Visual Sync

Guidelines for on-screen caption formatting and narration-visual sync. This skill produces a script and storyboard only — no audio is generated. The "captions" here are on-screen text overlays laid out for the visual design, not audio-synced subtitle timing.

## Narration-Visual Sync

### Timing Principles

1. **Lead with Visuals**: Show element slightly before mentioning
2. **Match Emphasis**: Stress words when key visual appears
3. **Allow Processing**: Pause after complex visuals
4. **Avoid Overload**: Don't describe everything on screen

### Sync Notation

```markdown
NARRATION                          | VISUAL
-----------------------------------|----------------------------------
"Now let's look at lift..."        | Lift arrow appears
[0.5s pause]                       | Arrow settles
"It comes from the wing"           | Zoom to wing
"Look at this shape"               | Wing cross-section appears
[1s pause]                         | Allow viewer to observe
"The top is curved"                | Top curve highlights
```

### Anti-Patterns

```markdown
✗ DON'T: "You can see the red arrow pointing up"
  (Viewer can already see it)

✓ DO: "This force—lift—pulls the plane upward"
  (Explains meaning, not visual)

✗ DON'T: Narration and visual showing different things

✓ DO: Narration explains what visual demonstrates
```

## On-Screen Caption Guidelines

On-screen captions are text overlays rendered as part of the visual composition (flat-geometric, Kurzgesagt-style). They are laid out for legibility and visual rhythm, not tied to an audio track.

### Caption Text Formatting

```markdown
Length:
- Maximum ~42 characters per line (English)
- Maximum 2 lines on screen
- Keep one idea per caption block

Punctuation:
- Use sentence case, no trailing period on a standalone caption
- Use "..." for trailing thoughts
- Keep punctuation minimal — the layout carries the rhythm

Line Breaks:
- Break at natural phrase boundaries
- Don't break in the middle of a term or compound noun
- Keep subject and verb together when possible
```

### Caption Segmentation (Layout, Not Audio Sync)

Caption blocks should be segmented for clean on-screen layout. Each block is a self-contained visual unit that appears and disappears as the scene progresses:

- **One idea per block**: Keep each caption block semantically complete; too short fragments the reading, too long overflows the layout
- **Break at natural pauses**: Split at sentence boundaries, commas, or semantic turns
- **Don't split a sentence across two blocks**: A sentence broken across two captions reads awkwardly and breaks the visual rhythm
- **Keep rhythm consistent**: Adjacent caption blocks should be similar in length

**Good segmentation:**
```
Block 1: "Have you ever wondered"
Block 2: "how an airplane stays in the air"
Block 3: "Today let's uncover the secret"
```

**Poor segmentation:**
```
Block 1: "Have you ever"              ← too short, incomplete idea
Block 2: "wondered how an airplane"   ← split across sentence
Block 3: "stays in the air today let's uncover the secret"  ← too long
```

### Example Caption Breakdown

```
Narration: "Lift is the most important force that makes a plane fly. It comes from the airplane's wings."

Captions (on-screen blocks):
[1] Lift is the most important force
[2] that makes a plane fly
[3] It comes from the airplane's wings
```

## Narration Quality Checklist

Before finalizing the script and caption layout:

- [ ] Read aloud — does it sound natural?
- [ ] Check word count fits the planned scene duration
- [ ] Verify technical accuracy
- [ ] Ensure audience-appropriate language
- [ ] Mark all pauses and emphasis
- [ ] Sync points with visuals documented
- [ ] No tongue-twisters or awkward phrases
- [ ] Consistent terminology throughout
- [ ] Caption blocks segmented for clean on-screen layout
